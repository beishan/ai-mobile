# A 版 PCB 生产说明

## 下单参数

- 外形尺寸：58 × 102 mm，矩形；
- 层数：四层；
- 板厚：1.6 mm；
- 铜厚：外层 1 oz，内层不低于 0.5 oz；
- 表面处理：建议沉金，适合 0.5 mm 间距 FPC 连接器；
- 阻焊颜色：不限；
- 常规最小过孔：外径 0.60 mm / 钻孔 0.30 mm；
- ESP32 模组中心散热焊盘包含 0.20 mm 成品孔径的热过孔，下单前确认板厂支持；
- 板载 MicroSD 卡座：Molex 104031-0811，推拉式，卡从 PCB 右侧插入；
- 层叠：F.Cu 信号层 / In1.Cu 接地层 / In2.Cu 接地层 / B.Cu 信号层；
- USB 工作在全速模式，本版未要求阻抗控制；如修改 USB 走线或板材层叠，
  必须重新检查 D+、D- 走线。

将 `gerbers/` 中的全部文件与 `drill/` 中的两个 Excellon 钻孔文件一起提交
给板厂。`gerbers.zip` 已包含这套完整文件。`assembly/positions.csv` 是贴片坐标，
`assembly/bom.csv` 是器件清单。

## 检查结果

- KiCad 电气及间距 DRC：0 个错误；
- 未连接焊盘：0；
- 剩余 DRC 信息：仅有丝印文字或位号被焊盘裁切的警告；
- 两个内层 GND 覆铜区已经重新填充；
- PCB 顶部 ESP32 天线净空区禁止布铜、走线、过孔和覆铜填充；
- Gerber 压缩包完整性检查通过。

## 装配及首板验证

1. 当前版本是 A 版样机，建议先生产并装配 1～2 块，不要直接批量生产；
2. 使用实物屏幕再次核对 FPC 接触面。J3 位于 PCB 背面，采用下接点连接器，
   丝印标有 Pin 1；金手指面与屏幕正面方向一致；
3. 只能使用带保护板的单节锂电池。插入前必须用万用表核对 JST 正负极，
   因为不同电池厂商的 JST-PH 极性可能相反；
4. 首次上电使用限流电源。安装 ESP32 模组或屏幕前，先测量 `SYS` 和 +3.3 V；
5. 安装屏幕后，在刷新过程中测量 PREVGH、PREVGL，并与屏幕供应商允许的
   电压范围比较；这些是墨水屏高压电源网络；
6. 检查 USB 枚举和刷写、充电电流、BQ24074 TS 状态、电池采样、板载 MicroSD 读写，
   以及墨水屏完整黑白刷新；
7. 上述项目全部通过后，再决定是否进入下一版或批量生产。

当前 BOM 记录了功能值和封装。委托贴片前，还应根据供应商库存确定最终厂家
料号，并逐项核对器件生命周期、封装尺寸和焊盘兼容性。
